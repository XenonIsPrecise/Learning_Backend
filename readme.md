# DevCamper API

> Backend API for DevCamper application which is a bootcamp directory wbsite

## Usage

Rename "config/config.env.env" to "config/config.env" and update with your own values

# Install Dependencies

```
npm install
```

## Run App

```
# Run in dev mode
npm run dev

#Run in production mode
npm start
```
